# 🏠 Surat House Price Prediction

## 📌 Project Overview
This is an end-to-end Data Science project that predicts house prices in Surat city using Machine Learning. The system takes user inputs such as area, BHK, location, and amenities to estimate property prices.

---

## 🚀 Features
- Data preprocessing and cleaning
- Feature engineering (area price index, amenities)
- Machine Learning model for prediction
- Flask-based web application
- Interactive user interface (HTML/CSS)

---

## 🛠️ Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn
- Flask
- HTML, CSS

---

## 📊 Dataset
Custom dataset created for Surat city using real estate data sources.

Main files:
- surat_house_price.csv
- amenities_data.csv
- area_price_index.csv
